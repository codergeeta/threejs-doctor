# @threejs-doctor/r3f

`DoctorCanvas` and `useDoctor` for React Three Fiber. Part of [threejs-doctor](https://github.com/codergeeta/threejs-doctor).

```bash
npm i @threejs-doctor/r3f
```

```tsx
import { DoctorCanvas, useDoctor } from '@threejs-doctor/r3f'

<DoctorCanvas profile="product" showOverlay>
  {/* scene */}
</DoctorCanvas>
```

Monorepo README: [github.com/codergeeta/threejs-doctor](https://github.com/codergeeta/threejs-doctor#readme).
